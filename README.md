🚀 ISS Live Tracker

Project Overview

ISS Live Tracker is a Python mini project that retrieves the current location of the International Space Station (ISS) using a public API.

It displays the latitude, longitude, date, and time, and opens the ISS location in Google Maps.

Features

- Fetches live ISS location.
- Displays latitude and longitude.
- Shows date and time.
- Opens ISS location in Google Maps.
- Automatically updates location every 5 seconds.
- Handles API connection errors.

Technologies Used

- Python
- Requests
- JSON
- Google Maps
- Webbrowser
- DateTime

Installation

Install the required package:

pip install requests

How to Run

python ISS_Tracker.py

Press "Ctrl + C" to stop live tracking.
